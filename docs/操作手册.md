## 日常使用

在项目目录运行 `python run.py` 启动界面。

点「立即检测」开始扫描：接了摄像头就持续扫描，没接就弹窗让你选一张图片。

右侧**始终列出全部 9 个工具**。识别到的打绿色勾、排在上半区，没识别到的打红叉、灰字排在下半区。判定依据是**最近 3 秒内有没有被检测到**，所以工具拿走超过 3 秒会掉到下半区，放回镜头前立刻升回去。

每 8 秒语音播报一次当前缺失的工具。「停止检测」会停在当前状态；「清空显示」立刻清空列表，摄像头还在跑的话下一帧识别到就会重新出现。

## 加新照片重新训练

三步，**一步一步跑，不是一次性粘进去**，每步等它跑完再跑下一步。

### 第 1 步：标注（一条命令搞定）

```
python scripts/open_labelimg.py --from "C:\Users\acad1\Desktop\你的照片文件夹"
```

自动建好下一个批次目录、把照片拷进去、生成类别文件，然后打开中文 labelImg，格式已预设成 YOLO。与以前批次重名的照片会自动跳过。

**每标完一张按 Ctrl+S 保存**。不想要的图直接跳过不存即可，不用删。

没标完、第二天接着标（**不要再带 `--from`**，否则会重复导入）：

```
python scripts/open_labelimg.py relabel9
```

### 第 2 步：合并数据集（约 1 分钟）

```
python scripts/prepare_relabel.py
```

看到 `data.yaml 已生成` 才算成功。它会把所有批次合并，按 70/20/10 切成 train/val/test。

### 第 3 步：归档旧结果 + 开训（约 3.5 小时）

PowerShell：

```
Move-Item data\training\runs\tool_yolo "data\training\runs\tool_yolo_archive_$(Get-Date -Format yyyyMMdd)"
python scripts/train_until_done.py
```

训练期间别关机、别休眠，也别跑 `python run.py`。崩了不用管，看门狗会自动从断点续上。查进度看 `data/training/watchdog_status.log`。

跑完会自动把新模型放到 `data/yolo/best.pt`，直接 `python run.py` 就是新模型。

## 必须避开的坑

这几个的共同点是：**出错不报错**，你以为成功了，其实白干。

| 坑 | 后果 | 怎么避开 |
| --- | --- | --- |
| 忘了归档 `runs/tool_yolo` | 看门狗以为已经训满 80 轮，直接退出并把旧模型重新部署一遍，一轮都不训 | 训练前先 `Move-Item` 归档，见上一节第 3 步 |
| 批次目录名不是 `relabel` + 数字 | 合并脚本只扫 `relabel*`，叫别的名字标了也不会进训练集 | 用 `open_labelimg.py` 建目录，它会自动命名并拦下错误 |
| 标完没按 Ctrl+S | 该张图不进训练集 | 每张都存；启动时会显示「共 N 张，已标 M 张」可核对 |
| 手动拷照片时保留了原时间戳 | 合并脚本靠「标签比图片新 60 秒」判断是否人工标过，会把你标的丢掉 | 用 `--from` 导入，脚本已处理 |

另外两件事：

- **模型不在 git 仓库的历史里自动备份**。重训会覆盖 `data/yolo/best.pt`，训之前把它拷一份到其它地方，新模型不如旧的就拷回去。
- **摄像头打不开**先跑 `python scripts/probe_camera.py` 看 Windows 能不能认到。全部报打不开就是接线、供电或驱动问题，跟程序无关；直播摄像机要用能传数据的 USB-C 线，4K 机常常还需要插 DC 12V。

## 什么在哪

| 路径 | 是什么 |
| --- | --- |
| `run.py` | 程序入口 |
| `data/yolo/best.pt` | **当前模型**，界面读的就是这个 |
| `data/yolo/class_map.json` | 9 个工具的英文类名→中文名，**顺序就是类别编号，不能改** |
| `data/training/relabel*/` | 各批次标注（images + labels） |
| `data/training/yolo_dataset/` | 合并后的训练集 |
| `data/training/runs/tool_yolo/` | 训练日志与权重 |
| `scripts/open_labelimg.py` | 建批次 + 导照片 + 启动中文标注 |
| `scripts/prepare_relabel.py` | 合并所有批次生成训练集 |
| `scripts/train_until_done.py` | 训练（崩了自动续训） |
| `scripts/train_yolo.py` | 训练本体，轮数、图像尺寸等参数在这里 |
| `scripts/probe_camera.py` | 摄像头排查 |

### 标签文件怎么看

每张图配一个同名 `.txt`，一行一个框：`类别编号 中心x 中心y 宽 高`，后四个数是相对图片尺寸的比例（0~1），不是像素。空的 `.txt` 是背景图，故意留空用来压误检，不是漏标。

类别编号：0 数字万用表、1 激光测距仪、2 绝缘钢丝钳、3 磁力线坠、4 网线测线仪、5 卷尺、6 绝缘电阻测试仪、7 胎压测试仪、8 电工胶带。

# 标注与训练流程（手工 labelImg 版，支持在另一台机器标注）

> 适用：你已经有一批工具照片，想**手工标注**后**重新训练** YOLO 模型，解决"认错/漏检"。
> 全程不依赖本项目的 GUI 训练按钮（本项目 GUI 没有），用 labelImg + 三个脚本即可。

---

## 总览：四步

```
①放照片        ②标注(labelImg)          ③回收           ④训练
photos ──▶ autolabel/images ──标注──▶ autolabel/labels ──▶ prepare_dataset ──▶ train_yolo
                  + classes.txt        (每图一个.txt)        生成 data.yaml      覆盖 best.pt → 重启GUI
```

标注**可以在另一台机器做**：把 `autolabel/` 文件夹拷过去标，标完把 `labels/` 拷回来。

---

## 第一步：照片放哪个目录

> 现状：`data/training/autolabel/` 里**已有约 712 张之前 SAM 自动标注的图**（环境现成）。
> 你现在是**增量**：① 翻出认错那两类（`multimeter_*`、`insulation_tester_*`）在 labelImg 里核对/改正旧标注；
> ② 把新拍的照片追加进 `images/` 再标。两者都标完一起重训，效果最好。

在**训练机**（也就是会跑训练的这台）建好这个结构（已存在则直接用）：

```
data/training/autolabel/
├── images/        ← 把所有要标注的照片(.jpg)放这里
├── labels/        ← 先建空文件夹，标注产生的 .txt 会进这里
└── classes.txt    ← 类别清单（下面给出，顺序不能改）
```

> 注意：`data/training/` 整个目录已 gitignore（太大不进 git），本地建即可。

**`classes.txt` 的内容**（必须是这 9 行、这个顺序，和 `data/yolo/class_map.json` 的 key 一字不差，否则训练出来类别会错位）：

```
multimeter
laser_meter
pliers
plumb_bob
cable_tester
ruler
insulation_tester
tire_gauge
tape
```

对应中文（仅供你标注时心里对照，文件里写英文）：

| 行号(类别id) | 英文 | 中文 |
|---|---|---|
| 0 | multimeter | 数字万用表 |
| 1 | laser_meter | 激光测距仪 |
| 2 | pliers | 绝缘钢丝钳 |
| 3 | plumb_bob | 磁力线坠 |
| 4 | cable_tester | 网线测线仪 |
| 5 | ruler | 卷尺 |
| 6 | insulation_tester | 绝缘电阻测试仪 |
| 7 | tire_gauge | 胎压测试仪 |
| 8 | tape | 电工胶带 |

> 拍照建议：在**摄像头实际安装位置/角度**拍（别用手机近距离特写），多换角度/远近/光线/遮挡。
> 重点补之前**认错**的那几对：数字万用表 vs 绝缘电阻测试仪、绿色工具 vs 胎压测试仪——多拍它们各自单独、清晰、多角度的照片。

---

## 第二步：装标注软件 labelImg

**本机已装好**（`labelImg.exe`）。如果是**另一台机器**，在那台装：

```bash
pip install labelImg
```

---

## 第三步：用 labelImg 标注

### 如果在另一台机器标注 —— 先把素材拷过去

把整个 `data/training/autolabel/` 文件夹（含 `images/`、空的 `labels/`、`classes.txt`）拷到标注机（U盘/网盘/局域网都行）。

### 启动 labelImg 并配置

在素材所在目录下，命令行启动（直接把图片目录和类别文件传给它）：

```bash
labelImg  autolabel/images  autolabel/classes.txt
```

**最省事**：用项目自带的一键启动脚本（自动指向 images/classes.txt/labels）：

```bash
python scripts/open_labelimg.py
```

或直接敲 `labelImg` 打开空界面，再手动设置。**关键设置（必须）**：

1. **左下角格式按钮**：点一下从 `PascalVOC` 切到 **`YOLO`**（这一步最关键，否则存的是 .xml 不是 .txt）。
2. **Open Dir**：选 `autolabel/images`。
3. **Change Save Dir**：选 `autolabel/labels`（标注的 .txt 存这里）。
4. 右侧类别列表会读到 `classes.txt` 的 9 个类。

### 标注操作（每张图）

| 操作 | 快捷键 |
|---|---|
| 画一个框 | 按 `W`，拖出矩形框住工具 |
| 选类别 | 画完弹出列表，点对应工具（如 `insulation_tester`） |
| 保存 | `Ctrl+S`（YOLO 模式会在 labels/ 写出同名 `.txt`） |
| 下一张 / 上一张 | `D` / `A` |
| 删除选中的框 | `Delete` |

**标注要领**：框要**紧贴工具轮廓**；一张图里有几个工具就框几个、各选各的类；画错的框删掉重画。一张图标完务必 `Ctrl+S` 再翻页。

### 标完拿回训练机

把标注机上的 `autolabel/labels/` 整个拷回**训练机**的 `data/training/autolabel/labels/`（覆盖/合并）。`images/` 和 `classes.txt` 训练机本来就有，不用拷回。

---

## 第四步：训练

回到**训练机**，在项目根目录 `auto_detection_ tool/` 下：

### 1) 切分数据集

先把 `scripts/prepare_dataset.py` 顶部的一个开关改一下（手工标注要用全部图，不做自动标注的筛选）：

```python
AUTO_ONLY = False     # 第 25 行，改成 False
```

然后跑：

```bash
python scripts/prepare_dataset.py
```

它会读 `autolabel/{images,labels,classes.txt}`，按 70/20/10 切分，生成 `data/training/yolo_dataset/`（含 `data.yaml`）。
> 没框的空图会被自动跳过（不当训练样本）。屏幕会打印"有效标注图 N 张"，确认 N 是你标注的数量级。

### 2) 开始训练

```bash
python scripts/train_yolo.py
```

- 底座用 `models/yolo11s.pt`（约 19MB，已 gitignore；这台机器上要有这个文件，没有的话 ultralytics 会自动下载）。
- CPU 训练约 **2–6 小时**（看图量），**训练期间别关那个窗口**。
- 配置在 `scripts/train_yolo.py` 顶部 `TRAIN_CONFIG`（`epochs=80, imgsz=416, device=cpu`）。有 N 卡可把 `device="cpu"` 改 `0`、`imgsz` 提到 640，快很多也更准。
- 训完**自动**把最佳权重复制到 **`data/yolo/best.pt`**，覆盖旧模型。

### 3) 看效果

```bash
python run.py
```

重启 GUI 后新模型即生效，点「📷 摄像头检测 / 🎬 视频检测 / 🖼 图片检测」验证之前认错的工具是否好了。

---

## 关键注意事项（踩坑预警）

1. **类别顺序绝对不能改**：`classes.txt` 必须和 `data/yolo/class_map.json` 的 key 同序（上面那 9 行）。顺序错了 → 训练出来"数字万用表"会被叫成别的名。
2. **labelImg 一定要切到 YOLO 格式**：默认是 PascalVOC（存 .xml）。如果不小心存成了 .xml，用 `python scripts/voc_to_yolo.py` 能转成 YOLO .txt。
3. **训练机要有 `models/yolo11s.pt`**：这是训练底座，gitignore 不进仓库。本机若没有，第一次跑 `train_yolo.py` 会联网自动下（需要能联网）。
4. **数据 > 调参**：解决认错/漏检，靠"补够摄像头实际场景的多样化照片"，远比改参数有用。每个易混工具补到 **100+ 张多角度**。
5. **想加背景负样本降误检**（可选）：把"画面里没有任何工具"的纯背景图放 `data/training/photo/背景图/`，`prepare_dataset.py` 会自动当空标签负样本喂进去。

---

## 命令速查（训练机上，按顺序）

```bash
# 0. 确认照片已放到 data/training/autolabel/images/ ，classes.txt 已就位

# 1. 标注（本机或拷到别的机器标，标完把 labels/ 放回 data/training/autolabel/labels/）
labelImg  data/training/autolabel/images  data/training/autolabel/classes.txt

# 2. 切数据集（先把 prepare_dataset.py 的 AUTO_ONLY 改成 False）
python scripts/prepare_dataset.py

# 3. 训练（自动覆盖 data/yolo/best.pt）
python scripts/train_yolo.py

# 4. 验证
python run.py
```
